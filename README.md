# Living World Map previews

This repository hosts automated browser previews for pull requests from
[`MuffinzCat/living-world-map`](https://<scrubbed-url-domain>/MuffinzCat/living-world-map).

Each open pull request is published beneath its own directory:

- `pr-31/`
- `pr-32/`
- and so on

The source repository creates or updates the matching directory whenever a pull
request changes and removes it when the pull request closes. This repository is
deployment output only; changes should normally come from that workflow.

The production site remains separate at `mapgen.muffincat.gay`.
